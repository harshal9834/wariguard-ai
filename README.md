# WariGuard AI

# VARI-SENSE – AI Powered Smart Wari Crowd & Resource Management System

## Project Overview

Design a modern, futuristic, government-grade AI-powered web and mobile application for managing the Wari pilgrimage. The platform should help coordinators, volunteers, police, medical teams, and pilgrims collaborate through one centralized dashboard. It should use Artificial Intelligence for crowd monitoring, congestion prediction, emergency response, resource allocation, and real-time decision support.

The UI should resemble a combination of:

- Google Maps

- Microsoft Azure Dashboard

- Google Cloud Console

- Emergency Command Center

- Smart City Dashboard

Use a clean, minimal, and professional interface with:

- White background

- Saffron (#FF9933)

- Dark Blue (#1E3A8A)

- Green (#22C55E)

- Light Gray

- Rounded cards

- Glassmorphism

- Modern icons

- Smooth animations

- Interactive charts

- Live maps
