================================================================================
THE PROBLEM (Why You Got 404)
================================================================================

Your application was MISCONFIGURED for its actual architecture.

WRONG Configuration (Static SPA):
  vercel.json
  {
    "outputDirectory": "dist/client",
    "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
  }
  
  PROBLEM: Expects index.html in dist/client/ (doesn't exist!)

ACTUAL Architecture (TanStack Start SSR):
  - Generates dist/client/ (browser assets)
  - Generates dist/server/server.js (backend entry point)
  - Server renders HTML dynamically (no index.html needed)
  - Server should handle all requests

RESULT: Vercel looked for index.html that doesn't exist → 404 error

================================================================================
ROOT CAUSE (Why It Happened)
================================================================================

The build generates TWO outputs:

dist/
├── client/              ← Browser-side bundles
│   ├── assets/         (JS chunks, CSS, images)
│   ├── favicon.svg
│   ├── robots.txt
│   └── NO index.html   ← This is normal for SSR!
└── server/             ← Server runtime
    ├── assets/
    └── server.js       ← This is the entry point!

But vercel.json was configured as if this were a static SPA:
  1. Pointed to dist/client only
  2. Expected index.html (doesn't exist)
  3. Ignored dist/server/server.js
  4. Had invalid "serverless" property (already fixed!)
  5. Had unnecessary "rewrites" to non-existent index.html

================================================================================
THE SOLUTION (What Was Fixed)
================================================================================

Updated vercel.json from:
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist/client",
  "serverless": { "maxDuration": 60 },           ❌ Invalid!
  "functions": { "api/**": { "maxDuration": 60 } },  ❌ Invalid!
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]  ❌ Wrong!
}

To:
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist/client"
}

WHY THIS WORKS:
✓ Removes invalid properties
✓ Keeps only essential configuration
✓ Vercel auto-detects TanStack Start framework
✓ Vercel automatically uses dist/server/server.js as entry point
✓ Server handles all routing and rendering
✓ No more 404 errors!

================================================================================
HOW IT WORKS NOW

Request Flow (FIXED):

1. User visits: https://your-app.vercel.app/
